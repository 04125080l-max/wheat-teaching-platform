# 冬小麦智能教学平台 · 田园物语

融合 AI 农业知识的冬小麦生长模拟教学应用（单文件静态 Web App）。

## 页面
- `/`（index.html）→ 学习空间 Home
- `home.html` → 学习空间（与根路径相同）
- `journey.html` → 冬小麦的一生（13 章节滚动教学导览）
- `index-v2.html` → 冬小麦生长模拟器（游戏 + 教学 + 学习档案）

## 功能
- 8 阶段冬小麦生长模拟（播种→成熟，242 天）
- 农事决策：浇水 / 施肥 / 打药 / 通风 / 补光
- 教学闭环：前测→学习→后测→学习增益报告
- 学习档案 Dashboard（概览 / 掌握度热力图 / 学习曲线 / 错题本 / 学习报告）
- 病害图鉴 + 拍照诊断（可选，需视觉模型 Key）
- 桌宠聊天：AI 农艺师（可选，需 DeepSeek Key；未配置时使用内置规则问答）
- Service Worker 离线支持

## 部署

纯静态站点，可部署到 Cloudflare Pages / GitHub Pages 等任意静态托管。
构建命令：`exit 0`（或留空）；输出目录：`.`

> 说明：AI 对话与拍照诊断采用“自带 Key（BYOK）”模式——Key 由访问者在自己的浏览器中配置并保存在 localStorage，代码中不包含任何硬编码密钥。
